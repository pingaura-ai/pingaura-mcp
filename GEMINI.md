# PingAura

PingAura measures how a brand appears in AI answers (ChatGPT, Gemini, Perplexity, Claude, Copilot and others).

Use the PingAura tools when the user asks about AI visibility, AI search share of voice, competitors in AI answers, which prompts mention their brand, site health for AI crawlers, or drafting and publishing articles.

- Start with `list-domains` to find the domain ID; most tools need it.
- Read tools are safe to call. Write tools (creating prompts, publishing articles, changing competitors) change the user's workspace: confirm with the user first.
